# QSQlab python library for the execution of Quantum System Quizzing Benchmark

> The aim of this workspace is to simplify the execution of the QSQ benchmark in quantum computing hardware and simulators.  
> This project makes use of the Qiskit Backend and QuantumCircuit classes for running sequences and gathering count data.

Under the folder "notebooks" you can see examples for running noisy simulations with QSQlab.  
You can install this project using pip under a command found in this repository's package registry.  

Under notebooks/creating_sim_example.ipynb you can find an example of how to use QSQlab to run simulations with Qiskit's AerSimulator
